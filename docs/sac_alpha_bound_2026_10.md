# α 的上界应当按 **α·H** 定，而不是按 α 定 —— 外加"α 该不该单调递减"的实测回答（2026-10）

> 本篇交付用户口径的 **"解决 SAC agent α 无限制增长"**，并把随行的两个问题一起钉住：
> **（a）** α 的上界该由什么量决定；**（b）** "后期逐步消除 α 的影响 / α 单调递减" 这个
> 想法在实测下成不成立。
>
> **本轮结论摘要（一句话一条，全部有表）**：
> 1. **理论约束只有 `α > 0 且有限`**。`α ≤ 1` 不是界，`[0.02, 5]` 里的两个数都是工程约定。
>    真正线性进 TD 目标的是 `α·H`（`y = r − γ(E[minQ] + α·H)`），所以唯一有依据的上界是
>    "**α·H 相对奖励/Q 尺度能有多大**"。⇒ 新增 `alphaHBudget`，**默认 3.0**。
> 2. **新默认的实测**：α 从"单调爬到 **2.62**（贴 5.0）"变成"停在 **0.96**，全程最大 **1.03**"；
>    Qspread **0.083 / 0.084**（基线 0.076 / 0.081，**是全部臂里最高的**）；
>    得分率 **75.0% / 80.0%**（基线 67.5% / 65.0%，**n=40 局/臂，+11pp ≈ 1.1 SE，不显著**）。
> 3. **"把 H̄ 的分母换成合法槽位数"单独做**（= 用户建议的第 1 步）**不是修复**，实测：
>    `--entropy-slots` 让 α 从"爬到 5.0"变成"**掉到 0.02**"（Qspread 0.023、得分率
>    **26.3%** vs 基线 66.3%）。它只是把上坡换成下坡 —— 两个方向都贴死边界。
>    **但配上"ratio = 可达最大熵 (1.0)"与预算就是一条可用口径**（`slots100` 臂：
>    α 0.93 / 1.05、得分率 75.0% / 75.0%，见 §3.5）。
> 4. **预算修不了"目标里 100% 是熵项"**：所有活着的手臂 `α·H / |y|` 实测都是 **~103%**，
>    因为 `E_π[min Q] ≈ −0.05`（目标网没动）。⇒ 预算是"止住发散 + 把 α 变成有界的量"，
>    **不是**"让 critic 拿到棋局信息"。
> 5. **顺带查实一个 clamp 语义坑**：`GradValue::clamp(c0, ci, cn)` 是"越界就置成 **ci**"
>    （`src/rl/parameter.hpp`），也就是 **α 跑出上界会弹回 0.02**，不是夹到上界。压到 1.0
>    的那一档实测撞上过（α 末值 0.683 而过程中到过 0.02）—— 一条锯齿。新口径自己夹到
>    **上界本身**；老口径（`alphaHBudget = 0`）保持逐位不变。

## 0. 机制：为什么 α 会"无限制增长"

```
π 只分布在 128 个哈希槽位上（槽位有碰撞）
   ⇒  H ≤ log(合法槽位数) < log(合法着法数) = H̄ / 熵比
   ⇒  α 的梯度 (dJ/dα = H − H̄) 恒为负
   ⇒  α 被单向推、没有不动点   ⇒  单调爬到上界 5.0
```

实测（`old-hb0` 臂 = `--alpha-h-budget=0`，20 局/seed，对 MCTS）：

| seed | α 起 → 末 | α·H | clamp 比例 | Qspread | 得分率 |
|---|---|---|---|---|---|
| 20240901 | 0.20 → **2.6201** | 4.37 | 71% | 0.076 | 67.5% |
| 777 | 0.20 → **2.6101** | 3.79 | 69% | 0.081 | 65.0% |

与 `docs/sac_critic_diagnosis_2026_09.md` §2 的 diag-new 逐位一致（局 1：α 0.2000→0.4081、
|y| 0.98、被夹 0%），也就是说**"α 单调爬升"这件事本身仍然可复现**（老口径没被动过），
本轮改掉的是"它爬到哪"以及"那个位置有没有依据"。

**这不是"信息熵算错了"**：H 按 π 累加是对的（`sacazagent.cpp` 的 α 段），坏的是 H̄ 的分母。
这也解释了为什么 α 的轨迹是一条**斜坡**而不是一条有反馈的曲线：误差项 `H − H̄` 就没有符号变化。

## 1. 改动：`alphaHBudget` —— 上界按 α·H 定

`src/sacazagent.h` / `src/sacazmoemlpagent.h` / `src/sacazmoetbagent.h` 新增成员：

```cpp
float alphaHBudget = 3.0f;   /* >0 生效; 0 = 关 = 改动前逐位相同 */
```

更新点在每个类的 α 更新之后（`alpha.RMSProp(...)` 之后）：

```cpp
上界 aMax = min(alphaCeiling, alphaHBudget / 本批 H 均值)
α < 0.02  -> 0.02
α > aMax  -> aMax                 /* 夹到上界本身 */
```

三点设计意图，逐条对应上面的结论：

* **夹的是效果，不是参数**：`α ≤ 预算 / Ĥ` ⟺ `α·H ≲ 预算`，**按构造**成立 ——
  不管 H 变不变、H̄ 可不可达、控制器有没有权威。单纯的 `alphaCeiling` 只挪动"顶到哪条线"。
* **不许用 `GradValue::clamp`**：它的语义是"越界置成 ci（= 0.02）"，会把"α 想变大"
  变成"α 归零"（见 §3.4）。
* **`alphaHBudget = 0` 走原来的 `clamp`，一行不动**：老口径（含 59e5233 的等价性口径）
  仍然可复现，回归检查仍能跑（§0 表就是它）。

**预算 3.0 这个数的来历**（不是调出来的）：它让 `α·H ≈ 2.4~2.5` 与 `clampTarget = 2`、
终局 ±1 同量级，而不是像基线那样让熵项（4.4）**越过整个值域**。换句话说，预算就是
"熵项允许把 TD 目标顶多远"的一条**显式声明**。`2.0` 也测了（§3.2），一样不塌，
被夹比例更低（38%/39%）—— 预算是一个**单调可调**的量，这才是重点。

**观测口径**：`TrainDiag` 的 `vEntSum / n` 就是 `α·H`；`bench_sac_learn` 每局那一行现在把它
印在最前面，并给出它占 `|y|` 的比例：

```
[①] α 0.2000→0.4081 (αH +1.04 = |y| 的 106%) | ...
```

**默认值改了哪些类**：`SACAZAgent` / `SACAZMoEMlpAgent` / `SACAZMoETbAgent`（三个都有这个成员）。
`SACAZLegacyAgent` **刻意不动**（它是 59e5233 的行为还原版，连成员都没有；
口径表见 `docs/agents_design.md`）。

### 3.1 「把分母换成槽位」单独做不是修复（用户建议的第 1 步被实测否掉）

`slots-bnd` 与 `slots098` 的数字**逐位相同** —— 因为 `slots-bnd` 是"槽位分母 + 默认预算 3.0"，
而 α 直接掉到 0.02，**预算从来没被碰到**。这条内部一致性同时说明：
**预算只封上界，对"下坡"完全无能为力。**

为什么 ratio 取 0.98 / 0.99 都不行：π 实测几乎就是均匀分布（`H / log(槽位数) ≈ 0.96~1.00`），
所以只要 `熵比 < 实际归一化熵`，`H > H̄` 恒成立 ⇒ α 单向下行到底（0.02）。

⚠ 用户原文给的 **"entropyRatio 取 0.85~0.95"** 在这一档下**恰好是最坏的一半**：
它会比 0.98 更快把 α 推到 0.02。这个建议只在"critic 已经活着、策略熵会随 α 变化"时成立；
现在策略熵对 α 没有响应（§3.3），靶子取多少都只会把 α 推到某一个边界。
⇒ **分母应当换**（它是真的不可达），但**必须与"ratio = 可达最大熵"一起换**，单独换是净损失
（66.3% → 26.3%）。

### 3.2 预算 3.0：α 有界，棋力与 critic 排序信号都没塌

* α 从"单调爬到 2.62"变成"停在 **0.96**（全程最大 **1.03**，没有一个是 5.0）"；
* 被夹比例 **71%/69% → 61%/68%**（预算 2.0 那档是 **38%/39%**）。
  被夹比例是 `α·H` 相对 `clampTarget=2` 的函数，所以它随预算**单调可调** ——
  这条比"降到某个数"更有用：`αH 4.4 → 71%`、`αH 2.4 → 61~68%`、`αH 1.7 → 38~39%`；
* Qspread **0.083/0.084** vs 基线 0.076/0.081（critic 的**排序**信号没变少，反而略高）；
* 得分率 75.0%/80.0%（合计 23 胜 1 负 16 和）vs 基线 67.5%/65.0%（16 胜 3 负 21 和）：
  合并 **77.5% vs 66.3%**，差 +11pp ≈ **1.1 SE，不显著**（n=20/seed）。
  **不说"更好"，只说"没塌"** —— 本轮的交付是"止住发散且不付棋力代价"，不是"涨棋力"。

### 3.3 预算修不了什么：组成没变

`αH/|y|` 那一列：**所有活着的手臂都是 ~103%**，包括预算档与 `slots100`。
原因不是 α，而是 `E_π[min Q] ≈ −0.05`（目标网仍停在随机初始化尺度，
见 `docs/sac_critic_diagnosis_2026_09.md` §3）。`|y| ≈ α·H` 的**比例**由 critic 决定，
不由 α 决定 —— 所以"让熵项退居次要"**不能靠压 α 完成**（那只是把 4.4 变成 2.4，比例还是 100%）。

### 3.4 附带查实：clamp 的语义是"越界弹回下界"

`src/rl/parameter.hpp`：

```cpp
void clamp(float c0, float ci, float cn) {
    val[i] = val[i] < c0 ? ci : val[i];
    val[i] = val[i] > cn ? ci : val[i];   // ← 越上界也是置成 ci, 不是 cn
}
```

于是 `alpha.clamp(0.02f, 0.02f, ceiling)` 的真实语义是
**"α 跑出 [0.02, ceiling] 就弹回 0.02"**。`alphaCeiling = 5.0` 时几乎撞不到（实测最大 3.42），
所以历史上没有暴露；但一旦把上界压到 1.0，撞上就是一条锯齿
（压上界那一档实测：α 末值 0.683 而过程中到过 0.02）。新口径因此**自己夹到上界本身**，
老口径（`alphaHBudget = 0`）保持原样。

### 3.5 可达靶子的正确用法：`entropyRatio = 1.0` + 预算

`slots100`（`--entropy-slots --entropy-ratio=1.0`，预算取默认 3.0）：
α 末值 0.9343 / 1.0486、`α·H` 2.50 / 2.36、Qspread 0.078 / **0.086**、得分率 75.0% / 75.0%。

也就是说：**分母换成槽位是对的**，但它的靶子必须取"可达最大熵"（ratio = 1.0），
而且**预算必须同时开着**（否则就是 `slots098` 那条 26.3% 的下坡）。
两条一起上之后，"目标熵不可达 ⇒ α 单向跑"这条**结构性**报警就消失了 ——
这也是为什么 `slots100` 的 α 是 0.93~1.05 而不是"贴哪个界"。

**本轮为什么不把它设成默认**：它要多改一个被测试钉住的默认值
（`test_sacaz` 断言 `SACAZAgent::entropyRatio == SACAZLegacyAgent::LEGACY_ENTROPY_RATIO`），
而它与新默认的棋力差落在噪声内（75.0% vs 77.5%）。**一次只改一件事**：
先把"没有依据的 α 上界"换成"按 α·H 定的上界"，靶子的口径留给下一轮（§5）。

## 4. 回答"α 该不该单调递减 / 后期逐步消除 α 的影响"

**不该"单调递减"，你要的效果是对的，但杠杆不是 α。** 四条依据：

1. **α 是拉格朗日乘子，它的符号本来应当双向**。策略熵掉到目标以下 ⇒ α 上升
   （防止过早收敛，这正是 SAC 自动温度里 α 上升的**正常**含义）；熵高于目标 ⇒ α 下降。
   写成单调曲线 = 退化成手工退火（开环 schedule）。
2. **"单调"本身就是现在这个 bug 的形状**：`old-hb0` 的 α 就是单调的（0.20→2.62 贴 5.0），
   `slots098` 的 α 也是单调的（→ 0.02 贴下界）。把方向反过来不是修复，是换一个边界贴。
3. **"消除影响"现在做 = 删掉唯一还在工作的脚手架**。三条实测同向：
   `alphaCeiling=0.1` ⇒ Q 间距 0.1945→0.0689、得分 31.2%；
   `entropyInTarget=0` ⇒ |Q| 0.041 / Qspread 0.013、得分 27.5%；
   本轮 `slots098` ⇒ Qspread 0.023、得分 **15.0%**。
4. **"后期"的正确判据是 critic 的健康度，不是局数**：`α·H / |E_π[min Q]|` 现在 ≈ 2.4/0.05 = 48 倍。
   只有这个比值下来了，压 α 才是在"降温"而不是在"删信号"。

**推荐的降温顺序**（都有现成旋钮，都可 A/B）：

| 顺序 | 做什么 | 旋钮 | 为什么是它 |
|---|---|---|---|
| 1 | 保持 scaffold，先让 critic 有信息 | `targetTau`/`replaceTargetIter`、数据量、蒸馏 | `αH` 占比由 `E[minQ]` 决定（§3.3） |
| 2 | 退火**目标熵比例** | `entropyRatio`（配 `entropySlotsAsLegal`，靶子取"可达最大熵"再往回收） | 无量纲、有界、跨局面同义的靶子；α 仍是控制器 |
| 3 | 退火 **α·H 预算** | `alphaHBudget`（3.0 → 2.0 → 1.5…） | 直接控"进目标的那一项"；被夹比例随它单调 |
| 4 | 条件触发（推荐的门槛） | 当 `Qspread`/`\|E[minQ]\|` 越过阈值才开始 2/3 | "后期" = critic 活着之后 |

**α → 0 也不是好终点**：自对弈需要残留熵，否则退化成确定性同型对局
（判和里"重复等着法"那一类，见 `bench_sac_learn` 的和棋成因分解）。

**关于"用 sigmoid 限幅"**（用户 2026-10 提问）：不解决问题。α 的控制器误差项
（`H − H̄`）是单向的，任何单调有界映射都**不会制造零点**，只会把"贴死边界"换成
"渐近趋近边界"。两种写法各有具体代价：重参数化 `α = α_max·σ(z)` 引入**无界内部状态** `z`，
float32 下 `z ≳ 20` 时 `σ(z)` 舍入成 `1.0f`、`σ' = 0` ⇒ 反传 `dz = dα/σ'(z)` 变 inf/NaN，
要防它就得再夹 `z`（等于回到硬夹，还多一层看不见的变量）；输出端软饱和
`α_max·tanh(α/α_max)` 没有内部状态，但它在边界附近把 `α_eff` 对 `α` 的导数抹向 0，
而且 `α·H` 的上界从"按构造 ≤ 预算"退化成"软性约等于"—— 恰好丢掉本轮唯一想要的性质。
另外本仓对软饱和有前科：`criticTanh`（`Q = tanh(z)`）实测让 Q 间距塌到 0.05~0.07
（`docs/dev_sacmoetb_strength_2026_09.md:416-430`），原因是搜索吃的是**排序差**。
**单侧约束用单侧机制**（`min` / 预算 / "超了就停"）最直接。

## 5. 已知未做 / 下一步

* **critic 侧（真正的瓶颈）**：目标网同步率与数据量 —— 本轮**没有**动它，
  所以 `E_π[min Q]` 依然是 −0.05，`αH/|y|` 依然是 103%。这是下一件事，
  顺序上**先于**任何进一步的 α 收缩。

  设成默认，并同步改 `test_sacaz` 里那条"当前口径 == 还原版口径"的断言
  （那条断言的存在意义是"别把还原版的 0.98 改回去"，改靶子口径时要一起改口径表）。
* **动作空间 8100 双射**（`legacyHashAction`）能直接消掉"槽位碰撞 ⇒ H 的上界低于 H̄"
  这条结构性理由；本轮没测。
* **界面口径**：三个类的 `selfCheckReport()` 已经会打印 `α 上界 / α·H 预算` 与预算行，
  但界面上的曲线仍然是 α 而不是 `α·H`。要不要把界面也换成"α·H 占 |y| 的比例"是产品决定。
* **注释级改动未重跑**：本表跑完之后只动过注释（`ahb3-c1` → 描述性措辞），
